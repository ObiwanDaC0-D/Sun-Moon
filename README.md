# Sun & Moon Observatory

A browser-based astronomy observatory for understanding the daily movement of the Sun and Moon. Explore celestial altitude, rise and set events, sky overlap, and changing daylight and lunar conditions through approachable charts and tables. Calculations and displayed times may be approximate and depend on location and available data.

## Purpose

An interactive solar and lunar observatory for exploring sunrise, sunset, moonrise, moonset, celestial altitude, and how long the Sun and Moon share the sky.

## Getting started

Open `index.html` in a modern browser, or publish the repository using GitHub Pages. The interface is intended for personal exploration and learning.

## Scope

This is an independent educational or personal-practice project. Features, accuracy, and browser support should be verified before relying on the app for consequential decisions.
