Data sources and limitations

The app attempts the US Naval Observatory complete Sun/Moon daily-data endpoint. Browser CORS rules or network outages can prevent access; when that happens, all rise/set values are calculated using SunCalc. SunCalc is an analytical approximation, not a high-precision JPL ephemeris. Altitude curves, lunar illumination, lunar age and future phase transitions are computed locally. Refraction, topography, elevation and lunar parallax affect observed rise/set times. Location uses your device time zone, which may be wrong when you select coordinates in another zone. USNO event times are converted using the returned time-zone offset; if the API's data shape is unsupported, calculated values are used instead. This is not suitable for safety-critical navigation.
